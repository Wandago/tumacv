# TumaCV

Paste a job posting → get a tailored CV + cover letter. Built for Kenyan job seekers. Pay-per-use via M-Pesa (planned).

## What's in the MVP

- Paste a job URL (BrighterMonday, Fuzu, MyJobMag, careers pages) or the description text
- Paste your CV / LinkedIn profile text once — saved in your browser, not on the server
- Three CV templates: Classic, Modern, Compact
- Tailored CV + cover letter generated by Claude, with a "fit check" showing matched and missing keywords
- Save as PDF via the browser's print dialog

Not yet included (deliberately): accounts, payments, DOCX export, marketplace. See roadmap below.

## Run locally

```bash
npm install
cp .env.example .env.local   # put your real key in .env.local
npm run dev                  # http://localhost:3000
```

Get an API key at https://console.anthropic.com (new accounts get free starter credit — enough for roughly 60+ generations).

## Deploy for free (10 minutes)

1. Push this folder to a new GitHub repo (free).
2. Go to https://vercel.com → sign up with GitHub (Hobby plan, free) → **Add New Project** → import the repo. Vercel auto-detects Next.js; don't change anything.
3. In the project's **Settings → Environment Variables**, add `ANTHROPIC_API_KEY` with your key.
4. Deploy. You get a free `your-app.vercel.app` URL with HTTPS.

**Important honesty note:** Vercel's free Hobby plan is for *non-commercial* use. It's perfect for validating the product with real users for free. The moment you start charging money, either upgrade to Vercel Pro ($20/mo) or move to Cloudflare (its free tier allows commercial use). Budget for this in the unit economics model — it's already a line item.

Also set a **spend limit** in the Anthropic console (Settings → Limits) so a traffic spike can't surprise you.

## Roadmap to paid product

1. **Auth + credits**: Supabase (free tier) — email/phone login, a `credits` column, decrement per generation, 2 free on signup.
2. **M-Pesa payments**: IntaSend or Paystack — STK push to top up credits (KES 50 single / KES 300 for 10). Both have sandbox modes and Node SDKs. Stripe is not the right tool for this market.
3. **DOCX export**: the `docx` npm package, generated client-side from the same structured CV JSON.
4. **Rate limiting**: Vercel KV or Upstash (free tiers) to stop abuse of the free tier.
5. **Marketplace** (phase 2, only after paying users): client requests board + contact unlock.

## Architecture

```
app/
  page.js                 UI: 3-step flow, templates, results, print
  api/generate/route.js   Calls Anthropic, returns structured CV JSON + letter + fit check
  api/fetch-jd/route.js   Fetches a job URL server-side, strips HTML to text
```

The API key lives only in server environment variables — it is never exposed to the browser.
